# 最小采购清单

面向第一阶段：Mac 本地摄像头 + Sipeed 6+1 USB 环麦 + 4090 远端算法服务 + 本地 ROS4HRI/注意力测试。

## 必须

| 物品 | 用途 | 备注 |
| --- | --- | --- |
| Sipeed 6+1 Mic Array 完整套件 | 原始多通道声学输入 | 确认包含 MA-USB8/UAC2 USB 声卡板、6+1 环麦板、排线、USB 线。 |
| 稳定 USB 数据线 | 8ch 48 kHz 原始音频 | 优先短线、屏蔽线；不要用只支持充电的线。 |
| 带供电 USB Hub | Mac/Jetson 同时接麦克风、摄像头、调试设备 | 阵列麦和摄像头一起用时更稳。 |
| 有线网络 | Mac/Jetson 与 4090 之间低延迟传输 | 千兆能跑，2.5GbE/10GbE 更稳；准备 Cat6/Cat6A 网线和交换机/路由器。 |
| 固定支架/安装板 | 麦克风阵列坐标系标定 | 需要让阵列的 0 度方向固定指向机器人正前方。 |
| 减震垫/软连接 | 降低电机、桌面、风扇振动传到麦克风 | 机器人运动测试会用到。 |

## 强烈建议

| 物品 | 用途 | 备注 |
| --- | --- | --- |
| 声级计 dB(A) | 复现你给的轻声/正常/提高音量/喊话测试 | 手机 App 只能粗测，正式记录建议独立声级计。 |
| 卷尺/激光测距仪 | 0.5m、1.5m、3m、6m 距离测试 | 配合地贴标点。 |
| 地面角度标记/量角模板 | 前后左右斜向与 DOA 标定 | 用于校准视觉/声学 azimuth。 |
| 可控播放音箱 | 电视、音乐、旁人声、机器人自播回声测试 | 音量可控，便于复现。 |
| USB 声卡或软件 loopback 方案 | TTS playback reference | Mac 可以先用软件 loopback；外置模拟喇叭链路建议 USB audio interface。 |
| 防风罩/海绵罩 | 户外风声测试 | 不解决强风，但能降低风噪冲击。 |

## 未来 Jetson 上位机

| 物品 | 用途 | 备注 |
| --- | --- | --- |
| Jetson Orin NX/AGX Orin 套件 | 机器人本体上位机 | 若 4090 仍在远端，Jetson 主要做采集、轻 VAD、ROS2 bridge、网络转发。 |
| Jetson 官方/稳定电源与散热 | 长时间测试稳定性 | 音频丢帧常来自供电、USB 和温度问题。 |
| NVMe SSD | 模型、日志、缓存 | 512GB 起步更省事。 |
| USB3 Hub 或稳定扩展板 | 多 USB 外设 | 需要确认 UAC2 多通道设备能稳定枚举。 |

## 不需要立刻买

| 物品 | 原因 |
| --- | --- |
| 第二套麦克风阵列 | 第一阶段先把 Sipeed 8ch 通道顺序、DOA、AEC、S2S 打通。 |
| 独立深度相机 | Mac 摄像头足够验证视觉输入和注意力原型；深度相机可在需要真实距离时再加。 |
| 云端音频采集设备 | 4090 侧只需要网络接收 Mac/Jetson 采集的 PCM，不需要直接接麦克风。 |

## 带宽估算

Sipeed 8ch 48 kHz S16_LE 原始音频约：

```text
48000 samples/s * 8 channels * 16 bits = 6.144 Mbps
```

即使加协议开销，千兆局域网足够；真正影响体验的是网络延迟、抖动和丢包。远程云 4090 如果不在同一局域网，建议用 WireGuard/Tailscale 并记录 RTT；实时对话目标最好把 4090 放在同城/内网。
