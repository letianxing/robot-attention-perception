## 不同频率怎么对齐（这是"融合"的实质）

| 源 | 频率 | 进注意力的方式 |
|---|---|---|
| 视觉人物 | 20fps | 每周期取最新快照（零阶保持），带 stamp，超 600ms 视为过期 |
| 身份识别 | 300ms | 同上，置信度随之变化，记忆通道整体乘它 |
| 声轨/VAD/方位 | 50Hz | 每周期取最新，超 700ms 过期 |
| ASR partial | ~100ms | 只作打断/轮次证据，不作语义 |
| ASR 最终句 | 句末+0.5~3s | **回溯判定**：finalize_gate 拿这句的起止时间去翻 50ms 网格的历史门控，不用"现在"的状态 |
| 记忆/熟悉度 | 后台异步 | 只读缓存，快循环从不阻塞等它 |
| 内生候选 | ≤每5分钟 | 不进第一层竞争，直接进工作区（它们没有模态） |

两种信号在竞争层里的处理方式不同：
- **连续量**（注视、身体朝向、语音活动）按水平进入，用 τ=1.2s 的积分累计，所以"看了一会儿"和"瞟一眼"不一样；
- **离散事件**（点名、答话、手势、惊跳）按 event_id 只施加一次脉冲，无论它在多少个周期里可见。

## 现在最要紧的三个缺口
1. 听觉候选没有按说话人拆分 → 多人同时说话时只有一条主导轨（Xiaomi 接进来也只能对着它抽）
2. 注意力不能反向控制视觉/听觉（没有 VisualAttentionBias / AuditoryAttentionTarget 接口）
3. 工作区每周期无条件广播，没有"证据不够就再看一眼"的选择
